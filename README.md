# 🌐 Personal Portfolio Website

This is my personal portfolio website built to showcase my skills, projects, education, and contact information.  
The website includes a working contact form that sends real-time emails using EmailJS.

---

## 🚀 Live Features

- 🔹 Responsive Design
- 🔹 Typing Animation Effect (Java Full Stack Developer)
- 🔹 About Me Section
- 🔹 Education Section
- 🔹 Projects Section
- 🔹 Contact Information Section
- 🔹 Working Contact Form (EmailJS Integration)
- 🔹 Clean and Modern UI

---

## 🛠 Technologies Used

- HTML5
- CSS3
- JavaScript
- EmailJS (for email functionality)
